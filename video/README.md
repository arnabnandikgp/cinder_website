# Cinder intro film

Standalone Remotion project. Nothing here is imported by the Next.js website.
Own `package.json`, lockfile, `node_modules`, public assets and output directory.
Root website TypeScript, ESLint and Prettier explicitly ignore this directory.
Website lint/format also ignore `.agents`, whose newly installed skills contain example code.

## Preview

```sh
cd video
npm ci
npm run dev
```

Open `http://localhost:3002/CinderIntro`. The main film is **27 seconds, 1920 × 1080 (16:9), 30 fps**.
The X revision uses the user's **Snap Crackle by Aetheric** soundtrack.
The original MP3 at `video/Aetheric - Snap Crackle (freetouse.com).mp3` is preserved;
a playback copy lives at `public/audio/aetheric-snap-crackle.mp3`. Both are Git-ignored.
On another machine, provide that playback file before previewing/rendering.
Text layers are named and editable in Studio; the network geometry is computed in code.
The `Scenes` folder in Studio also exposes isolated scene timelines.

## Edit points

- `src/scenes/NetworkScene.tsx`: the opening, feature text and scene timing.
- `src/components/NetworkDiagram.tsx`: venue badges, routed packets, pooled inputs and privacy boundary.
- `src/components/CinderMark.tsx`: one persistent logo that carries into the end card without a duplicate-image crossfade.
- `src/scenes/EndCard.tsx`: closing promise and follow CTA.
- `src/motion.ts`: faster scatter, accelerated orbit, orbit-to-fan paths and connector/packet geometry.
- `src/venues.ts`: venue names and local logo files.
- `src/Root.tsx`: composition size, duration and frame rate.
- `src/components/Soundtrack.tsx`: replace the music, source offset, level and fades here.
- `scripts/make-audio.mjs`: archived, rejected synthesized score. Not used by the composition.
- `ASSETS.md`: official artwork sources and outstanding release checks.
- `STORYBOARD.md`: approved narrative and timing.

All Remotion packages are pinned together. Do not install them into the website package.
The logo uses the approved 634 × 754 repaired master, preserving its full lower tip.
The privacy scene uses a code-drawn lock below the mark, replacing the previous record bars.
The September 25 logo/lock revision keeps the 27-second edit, faster motion and soundtrack unchanged.
The final wordmark revision uses native SVG letter outlines, rebuilt against the intact
reference lettering: no stray symbol fragment above the “d,” ragged bitmap edges, or font dependency.
The same central logo remains mounted through the ending and eases directly to top center,
with zero starting/ending velocity and acceleration. The final label reads
"Prime brokerage for solana perps." Website assets are not modified by this video-only revision.
The introduction revision adds “Introducing Cinder. Prime brokerage for Solana perps.”
before “One account.” The hook/assembly/orbit are retimed without extending the 27-second
film or changing its music. Pooled inputs are native head-and-shoulders user silhouettes.
`captions.json` is the timed Caption-shaped source; `node scripts/export-captions.mjs`
regenerates the optional `captions.srt` sidecar.
Arial follows Cinder's current typography; systems without Arial use Helvetica/sans-serif.
The initial render was made on macOS. For pixel-identical renders elsewhere, provide an
appropriately licensed local Arial font or approve a bundled replacement.

## Release status

Review cut, not an announcement of live integrations. The user selected BULK, Pacifica,
Velocity, Phoenix and GMTrade; integration status is still unconfirmed. The on-screen
integration/development disclaimer was removed at the user's request.
Confirm the list/status and brand permissions before publishing. No affiliation is asserted.
Fees are a product goal, not a promised discount. The video deliberately shows no latency,
performance, venue-count or fee savings statistics. Privacy comes after the account story.

No voiceover: the text carries the story. The first draft's
music was generated by `scripts/make-audio.mjs`, not sourced from a library or artist.
It was rejected and is no longer referenced. Keep the file only as source history.
The replacement is the user's supplied **Snap Crackle by Aetheric**, sourced from Free To Use.
It uses one continuous 62–89s excerpt, attenuated to 42%, with short edge fades.
The track's natural ending arrives with the closing card; no generated tones are layered over it.
Review the soundtrack in the exported cut before posting.

**Publishing clearance:** Free To Use's [official guidance](https://freetouse.com/blog/royalty-free-corporate-background-music)
says brand/product promotions require a Commercial Plan or Pro License. A free download alone
does not establish that coverage. User confirmation of the applicable license is still needed
before publication; this local review render is not a license purchase or rights clearance.
Remotion's own commercial licensing terms apply to your team separately.

## X delivery

The export uses H.264 in MP4, yuv420p and BT.709 at 30 fps. The 1920 × 1080 dimensions
fit [X's published upload limits](https://help.x.com/en/using-x/x-videos), checked 2026-09-25.
The previous 4:5 size was also supported; this revision uses a purpose-built landscape
composition, not stretching, pillarboxing or cropping the portrait video.
